Welcome to my **Java + Data Structures & Algorithms journey**.

I am learning Java from the fundamentals and building a strong
programming foundation before moving deeper into **DSA, problem solving,
coding platforms, and technical interview preparation**.

learn, the programs I write, the mistakes I make, and the progress I
